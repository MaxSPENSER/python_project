# Анализ и потоковая обработка логов интернет-магазина

## Описание проекта

Проект демонстрирует:

- Аналитику данных через pandas
- Потоковую обработку данных без загрузки в память
- Использование ООП
- Пользовательские исключения
- Декораторы
- Паттерн Strategy
- Тестирование через pytest

---

## Источник данных

CSV-файл с логами заказов интернет-магазина.

Пример структуры:

| Поле | Описание |
|------|-----------|
| order_id | ID заказа |
| user_id | ID пользователя |
| product | Название товара |
| price | Цена товара |
| quantity | Количество |
| date | Дата заказа |

Данные содержат проблемы для очистки:
- Отрицательные цены
- Пустые значения
- Пропущенные поля
- Дубликаты

---

## Реализованные шаги pandas

В классе `PandasAnalytics` реализованы следующие шаги обработки:

1. Удаление дубликатов (`drop_duplicates`)
2. Удаление пропусков (`dropna`)
3. Преобразование типов (`astype(float/int)`)
4. Создание колонки `total = price * quantity`
5. Фильтрация некорректных значений (`price > 0`)

---

## Потоковая обработка

Реализована ленивая (потоковая) обработка данных без загрузки всего файла в память:

- **DataSource** — итерируемый объект для чтения CSV
- **DataCleaner** — генератор с `yield` для очистки данных
- **FilterIterator** — ленивый фильтр с поддержкой стратегий

Преимущества:
- Экономия памяти при работе с большими файлами
- Обработка данных по мере поступления
- Пропуск ошибочных строк без остановки обработки

---

## Паттерн проектирования

Используется паттерн **Strategy** (Стратегия).

- `FilterStrategy` — абстрактный базовый класс
- `PriceFilterStrategy` — конкретная стратегия фильтрации по минимальной цене
- `FilterIterator` — контекст, использующий стратегию

Это позволяет легко добавлять новые стратегии фильтрации без изменения существующего кода.

---

## Декоратор

В проекте реализован декоратор `@log_execution` в файле `decorators.py`.

Он используется для:
- Логирования начала выполнения функции
- Измерения времени выполнения
- Логирования завершения функции

Применён в методе `process()` класса `PandasAnalytics`.

---

## Исключения

Определены пользовательские исключения в `exceptions.py`:

- `InvalidDataError` — ошибка некорректных данных
- `FileFormatError` — ошибка формата файла

Исключения выбрасываются:
- `FileFormatError` — при попытке загрузить не-CSV файл в `DataSource`

Исключения обрабатываются:
- В `main.py` — перехват и вывод сообщений об ошибках
